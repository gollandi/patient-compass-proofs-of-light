# Patient Compass Suite — Proofs of Light

A static, responsive presentation of the Patient Compass Suite.

This repository contains the approved presentation only. Images and brand artwork are embedded in `index.html`; there is no server, sign-in or build dependency.

`teaser/` is the short theatrical doorway into the presentation (the Chelsea edition). It is derived from the Suite source by `apps/suite/scripts/teaser-edition.mjs` in the Patient Compass Suite repository, never edited by hand here: only its story and pilot links and its footer differ from the Suite edition.

Published with GitHub Pages from the root of `main`.
